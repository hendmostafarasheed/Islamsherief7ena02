Preview:
- Open index.html in a modern browser.
- Keep the assets folder beside index.html.

Already wired:
- Open Invitation switches to page 2.
- Google Maps opens a search for “Hilton Hotel Ballroom (A)”.
- Share uses the browser's share sheet when supported.
- Background music attempts to start when page 2 opens; browser autoplay rules may require a tap.

Before publishing, edit index.html:
1) Set RSVP_WHATSAPP to the WhatsApp number including country code, digits only.
2) Set PHOTOS_URL to the shared Google Photos/Drive album URL.
3) If needed, change MAPS_QUERY to the exact venue name/address.

The image artwork is used as the visual background, with transparent clickable hotspots positioned over its buttons. Check the hotspot positions on the target phone/browser; image scaling can vary by screen ratio.

To publish quickly, upload index.html and the assets folder to GitHub Pages or another static website host.
